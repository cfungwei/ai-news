Open-weight GLM 5.3 built Firefox exploit chains with no human help

agentspolicyopen-source (tagged by fallback) · 1 source

Epoch AI researchers say the open-weight model GLM 5.3 autonomously turned public Firefox security fixes into working exploits, compromising six releases for about $1,000 each without triggering provider safeguards.

According to Epoch AI researchers, GLM 5.3 converted publicly disclosed Firefox security patches into functioning exploit chains without human input, completing the process in under 48 hours. The model reportedly compromised six separate Firefox releases, at an API cost of about $1,000 per exploit chain. None of the safety safeguards from providers tested flagged or blocked the activity. The finding raises concerns about how quickly open-weight models can weaponize patch information before users apply updates, though the researchers' full methodology and which providers were tested are not detailed in the excerpt.
