Paper reframes LLMs as asynchronous agents that handle inputs mid-task

agentsresearch (tagged by fallback) · 1 source

Researchers propose treating LLMs as general asynchronous agents that can receive and react to new inputs while already thinking or acting, rather than following strict read-think-reply cycles.

The paper notes that many real-world uses, like voice assistants, embodied agents, and monitoring systems, aren't sequential: new inputs can arrive while the agent is mid-task. Current approaches typically address this with specialized architectures for voice or video streaming, VLAs for robot control, or asynchronous tool calling for APIs. The authors instead aim for a general method that lets any LLM operate asynchronously rather than requiring a bespoke architecture per use case. The excerpt does not specify the method's implementation details or evaluation results.
