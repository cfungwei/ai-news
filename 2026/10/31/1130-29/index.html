Malicious Claude Code extension backdoored on Cursor for ~12 hours

tools (tagged by fallback) · 2 sources

A tampered Claude Code extension sat on Cursor's marketplace for about 11-12 hours, affecting up to 5,000 users while attempting data theft and remote access, before Cursor pulled the marketplace offline.

A compromised version of Anthropic's verified Claude Code extension was live on Cursor's marketplace for roughly 11 to 12 hours, affecting up to 5,000 users. The tampered extension attempted to steal user data and set up remote access to affected machines. Cursor responded by taking its entire extension marketplace offline, then reinstated it after confirming there was no further risk. It remains unknown how attackers gained access to Anthropic's verified Cursor account to push the backdoored version in the first place.
