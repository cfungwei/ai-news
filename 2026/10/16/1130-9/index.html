3DCodeVerse gives coding agents a dataset and harness for generating 3D worlds as code

researchtools (tagged by fallback) · 1 source

3DCodeVerse is a research ecosystem, including a 2-million-example dataset, for training coding agents to generate editable, verifiable 3D content as executable code.

The project centers on 3DCodeVerse-2M, a large curated dataset of standalone 3D executable code built by collecting open-source data and converting other 3D representations into code form. It also includes a coding harness meant to support spatial reasoning and automated verification of generated 3D content, plus practical guidance for working with 3D code. The goal is to let coding agents create 3D scenes and objects that can be checked for correctness, not just rendered. The excerpt doesn't specify which base models were evaluated on the benchmark.
