Latent Space: how Stanford's CS146S teaches 'AI-native' engineering

agentsother (tagged by fallback) · 1 source

A Latent Space post and podcast episode with Mihail Eric describe Stanford's CS146S course, where students learn an unfamiliar repo and propose changes since coding agents can now finish last year's homework instantly.

The course is taught alongside Monaco's engineering team. In its second run, Eric brought open-source maintainers into the class so students practice navigating a real codebase and proposing a change, rather than solving self-contained assignments a coding agent could one-shot. The piece frames this as a response to coding agents being able to finish last year's homework in a single prompt.
