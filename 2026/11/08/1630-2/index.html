Alibaba's Co-Design Bench finds AI coding agents fail most real tasks

agentsmodels (tagged by fallback) · 1 source

Alibaba's new Co-Design Bench tests AI coding agents on real user requests that previously tripped them up, finding even the top model fully solves only 26.4% of tasks.

GPT-6 Astra, the top performer on Alibaba's Co-Design Bench, fully solved only 26.4 percent of tasks, despite the same models scoring above 99 percent on older coding benchmarks. The benchmark draws on real user requests that have already tripped up coding agents in practice, rather than synthetic test cases. The large gap between old and new scores suggests older benchmarks overstate how well AI coding agents handle messy, real-world requests, leaving roughly three-quarters of tasks still needing human cleanup.
