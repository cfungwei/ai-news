### R2Orch uses recursive self-play to train AI agent orchestrators
`agents` `research` (tagged by fallback) · 1 source

A new paradigm, R2Orch, runs an inner self-play loop to improve how AI agents are orchestrated, aiming to fix hand-designed curricula, advantage collapse, and unreliable per-skill evaluation signals in existing methods.

<details><summary>More</summary>

Agentic orchestration coordinates multiple AI skills to solve complex tasks, but current training methods rely on hand-designed curricula and can suffer 'advantage collapse' when all rollouts for a task reach the same outcome. Evaluation signals that score each skill with one noisy number add further instability. R2Orch addresses this with Recursive Self-Play Orchestration: an inner loop of self-play that improves the orchestrator itself, inside what the paper calls a skill-internalization loop. The excerpt does not specify which benchmarks or models the method was tested against.

- [Hugging Face Daily Papers: R^2Orch: Recursive Self-Improvement for Agent Orchestration via Self-Play within a Skill-Internalization Loop](https://huggingface.co/papers/2610.22740)

</details>

### CEPO splits coordinator and executor prompts in multi-agent systems
`agents` `research` (tagged by fallback) · 1 source

CEPO is a new framework for prompt optimization in multi-agent systems that separates system-level coordination from agent-level execution, using a shared coordinator prompt alongside agent-specific executor prompts.

<details><summary>More</summary>

Multi-agent systems need both coordination across agents and specialized execution within each agent, but most prompt-optimization methods couple the two inside agent-specific prompts. Coordinator-Executor Prompt Optimization (CEPO) instead separates the two: a shared coordinator prompt handles system-level coordination, while agent-specific executor prompts handle task execution, and the two are updated according to their distinct roles. The excerpt does not include benchmark results, so how much this separation improves over coupled approaches isn't clear yet.

- [Hugging Face Daily Papers: CEPO: A General Framework for Improving Prompt Optimization in Multi-Agent Systems](https://huggingface.co/papers/2610.34722)

</details>
