### SpecSlot decouples image detail from token count in pixel Transformers
`research` (tagged by fallback) · 1 source

A new paper introduces SpecSlot, a pixel-space rectified-flow Transformer that separates fine image detail from the number of tokens used, letting low-frequency structure use global attention while high-frequency detail is modeled locally.

<details><summary>More</summary>

Pixel-space generative Transformers normally assign one token per image patch, so adding finer detail means adding more tokens and making global attention more expensive. The authors argue this isn't necessary: low-frequency structure benefits from global information exchange, but high-frequency detail can be captured with local modeling instead. Based on that observation, they introduce SpecSlot, a pixel-space rectified-flow Transformer that decouples output detail from token length. The excerpt is cut off before describing how the architecture achieves this split or what results it reports.
