### CarryOn proposes object-oriented context for long-horizon AI agents
`research` `agents` (tagged by fallback) · 1 source

Researchers introduce CarryOn, a context runtime that organizes long-horizon agent memory around reusable task objects instead of replayed interaction histories.

<details><summary>More</summary>

Today's long-horizon agents typically re-process long interaction histories to recall how they reached their current state, even though that state already captures their progress. CarryOn reframes this by organizing an agent's context around reusable, object-oriented task objects rather than compressed or reconstructed histories. The approach asks whether continuation can be built from structured progress objects instead of replaying how that progress was made. <details><summary>More</summary>

Google has released Harness2 as open source, a system that turns any AI harness into something that improves itself over time. A harness here covers everything surrounding the underlying model: its system prompt, tools, memory, skills, and subagents, which are normally designed once and then used unchanged for every task. With Harness2, the agent instead proposes changes to its own harness, runs a few candidate versions, and picks the better one by comparing how they perform.
