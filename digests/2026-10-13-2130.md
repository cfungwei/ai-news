### GroundAnything replaces autoregressive visual grounding with parallel diffusion
`research` `models` (tagged by fallback) · 1 source

A new paper proposes bidirectional diffusion for visual grounding, letting spatial predictions emerge in parallel instead of token-by-token, aiming for faster, more accurate results.

<details><summary>More</summary>

The paper argues that autoregressive grounding models serialize spatial predictions, adding sequential latency and forcing an artificial left-to-right order on outputs. The authors reframe grounding as visual evidence extraction, where objects, locations, and spatial relations are jointly constrained by the image and query rather than generated in sequence. This framing motivates a bidirectional diffusion approach that lets spatial hypotheses emerge in parallel and be refined jointly. The method is presented under the name GroundAnything, targeting what the authors call 'flash speed' grounding. The available excerpt does not specify benchmark results or release details.

- [Hugging Face Daily Papers: GroundAnything: Reconciling Parallel Decoding with Precise Visual Grounding at Flash Speed](https://huggingface.co/papers/2609.39600)

</details>

### Geoffrey Huntley: pre-commit hooks can steer coding agents mid-task
`agents` `tools` (tagged by fallback) · 1 source

In a quoted post, developer Geoffrey Huntley describes using a pre-commit hook that fails a commit and injects a prompt telling a coding agent to use his diagnostics library instead of bypassing it.

<details><summary>More</summary>

The quote, shared via Simon Willison's blog, comes from developer Geoffrey Huntley discussing how he keeps AI coding agents aligned with his preferred tooling. Rather than relying on agents to read and follow instructions in a file like AGENTS.md, which can drift out of date, Huntley writes a pre-commit hook that checks the git diff for direct calls to observability modules that bypass his diagnostics library. When it finds a violation, the hook fails the commit and injects a prompt telling the agent to use the diagnostics library instead. Huntley says this approach reliably fixes the agent's behavior, calling the result 'ten out of ten.'
