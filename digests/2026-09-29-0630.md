### FuseReg regularizes layer fusion in representation autoencoders
`research` (tagged by fallback) · 1 source

A new method called FuseReg addresses the trade-off between fine pixel detail and generation quality when choosing which encoder layers to fuse in representation autoencoders.

<details><summary>More</summary>

Representation autoencoders reuse a pretrained visual encoder's features as latents for both reconstruction and diffusion-based image generation. Choosing which encoder layers to fuse involves a trade-off, since shallower layers preserve pixel detail while deeper layers tend to improve generation metrics. Rather than relying on a fixed heuristic, the authors introduce FuseReg, a regularization approach to the layer-fusion choice that aims to close this reconstruction-generation gap.

### Disaggregated Quantization splits LLM prefill and decode formats

A technique called Disaggregated Quantization (DQ) applies different precision formats to prefill versus decode phases of LLM inference, improving decode-heavy accuracy without added cost.

<details><summary>More</summary>

Prefill and decode favor different quantization approaches: low-precision arithmetic speeds up prompt processing, while compact weights cut memory traffic during generation. The authors propose Disaggregated Quantization (DQ), which specializes compute formats, weights, and storage placement separately for each phase. Tested on Qwen 3 and Gemma 3, removing activation quantization specifically during decode improved accuracy on decode-heavy tasks without increasing inference cost.

### SLCA-GRPO fixes credit misattribution in tool-calling reinforcement learning
`research` `agents` (tagged by fallback) · 1 source

SLCA-GRPO addresses a failure mode in reinforcement learning for tool-calling agents, where gradient noise from natural-language summaries leaks into tool-decision tokens.

<details><summary>More</summary>

Tool-calling agents produce heterogeneous outputs that interleave structured tool invocations with user-facing natural-language summaries, which creates a problem for standard on-policy RL algorithms like GRPO: they broadcast one trajectory-level reward to all tokens indiscriminately. This lets gradient noise from summary generation leak into tool-decision tokens, causing cross-segment credit misattribution and brittle training. SLCA-GRPO is proposed to resolve this misattribution.
