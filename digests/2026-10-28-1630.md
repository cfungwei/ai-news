<details><summary>More</summary>

### HABIT-Bench benchmark tests how agent memory infers user habits
`research` `agents` (tagged by fallback) · 1 source

A new benchmark, HABIT-Bench, evaluates how well LLM agent memory systems can infer user habits from weak, long-term evidence spread across conversations.

<details><summary>More</summary>

The paper notes that in long-term interactions, users reveal habits through their choices and actions, which agents must infer across conversations. Individual observations often provide only partial evidence about a habit or when it applies. The authors argue that simply retaining past interactions does not guarantee an agent can infer habits and apply them appropriately. HABIT-Bench is introduced to evaluate agent memory systems specifically on this longitudinal, weak-evidence habit induction problem.

- [Hugging Face Daily Papers: HABIT-Bench: Evaluating Habit Induction from Longitudinal Weak Evidence in Agent Memory](https://huggingface.co/papers/2610.24520)

</details>

<details><summary>More</summary>
