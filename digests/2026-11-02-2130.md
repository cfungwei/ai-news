### REA framework pairs slow foundation-model reasoning with fast robot control policies
`research` `robotics` (tagged by fallback) · 1 source

A new paper introduces REA, a runtime that lets a foundation-model 'brain' plan asynchronously while fast policies like VLAs act as a reactive 'cerebellum' for robots.

<details><summary>More</summary>

The paper argues that foundation models are increasingly reliable at high-level reasoning but too slow and costly to control robots in real time, while fast policies such as vision-language-action models and whole-body controllers react quickly but generalize poorly. REA is proposed as a runtime that routes between these two systems asynchronously, letting the deliberative model plan while a reactive layer handles moment-to-moment control. The authors note that existing approaches are typically built and evaluated on incompatible stacks, which REA aims to address. The excerpt does not specify which robots or tasks were used to test the system.

- [Hugging Face Daily Papers: REA: A Routed Embodied Agent Runtime for Asynchronous Brain-Cerebellum Control](https://huggingface.co/papers/2610.42053)
