### Researchers propose LowRAM to shrink LLM KV cache by predicting values from keys
`research` (tagged by fallback) · 1 source

A new technique, LowRAM, fits a lightweight predictor at test time to estimate attention values from their keys, cutting KV cache memory without retraining and complementing existing compression methods.

<details><summary>More</summary>

The KV cache that autoregressive decoding relies on grows linearly with context length, limiting batch size and throughput. Prior post-training compression methods have targeted redundancy across tokens, layers, or feature dimensions, or reduced numerical precision. This paper identifies a separate axis: within each attention head, value vectors can largely be predicted from their corresponding keys. It proposes value cache amortisation, fitting a lightweight predictor per head at test time to exploit that redundancy, though the excerpt does not specify how much memory this saves in practice.

- [Hugging Face Daily Papers: LowRAM: Low-Rank Keys and Amortised Values for Composable KV Cache Compression at Test-Time](https://huggingface.co/papers/2611.07025)

</details>
