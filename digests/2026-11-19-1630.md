### CurvDelta uses low-curvature parameter updates to protect LLM capabilities
`research` (tagged by fallback) · 1 source

CurvDelta is a new fine-tuning framework that bakes a "capability preservation" constraint into how model updates are parameterized, aiming to adapt LLMs without degrading their general abilities.

<details><summary>More</summary>

A common failure mode when adapting large language models is capability preservation: an update can hit its target while quietly degrading the model's general abilities elsewhere. CurvDelta addresses this by analyzing the local geometry of the preservation constraint around the pre-adaptation model, then constructing a low-curvature space in which parameter updates can move toward the new target while leaving the preservation loss nearly unchanged. The method is described as scalable, suggesting it is meant to work on large models rather than only small demonstrations. The excerpt is cut off before specific benchmarks, model sizes, or quantitative results, so how much capability loss it avoids versus standard fine-tuning isn't yet clear.

### HINT-WAM trains robot world-action models on hindsight-informed data
`robotics` `research` (tagged by fallback) · 1 source

HINT-WAM is a new post-training method for "world action models" used in robot manipulation, aiming to close the gap between offline demonstration training and reliable task execution.

<details><summary>More</summary>

World action models combine action generation with predictions of future visual dynamics, and have shown promising generalization and data efficiency in robot manipulation. Turning that promise into reliable task execution has been difficult for existing post-training methods: offline supervised fine-tuning gives dense supervision on expert trajectories, but its flow-matching action expert is trained only on noised demonstration actions and never on the intermediate states a robot would actually encounter during execution. HINT-WAM's "hindsight-informed" name suggests it trains using information only available after a trajectory unfolds, though the excerpt cuts off before explaining the exact mechanism. Which robots, tasks, or benchmarks were used to evaluate the method isn't given in the excerpt.
