### Anthropic's Claude designs protein binders to target scorpion venom
`research` `products` (tagged by fallback) · 1 source

Anthropic says Claude independently designed protein binders against deadly scorpion neurotoxins, screening over 318,000 candidate designs down to two that bind tightly to a toxin from a Mexican scorpion species.

<details><summary>More</summary>

Out of more than 318,000 AI-generated designs, 211 were tested in the lab, and 17 met the criteria the researchers set. The two strongest binders target Cn2, a neurotoxin from a Mexican scorpion, binding to it extremely tightly. Whether the designs would actually work as an antivenom in practice remains an open question, according to the report. The work is attributed to a project called Claude Science.

### Matrix-Game 4.0 separates game-engine logic from video generation
`research` `agents` (tagged by fallback) · 1 source

Researchers unveil Matrix-Game 4.0, a playable game-world system that splits execution from visual generation: a lightweight engine holds persistent world state while a coding agent turns player ideas into game rules.

<details><summary>More</summary>

The system separates game execution from visual generation through what the authors call an executable game harness. A lightweight game engine maintains persistent world state and executes interaction rules, rather than leaving that to the video model. A multimodal coding agent translates player ideas into executable game logic. The authors frame this design as a roadmap for the next generation of Matrix-Game systems, built to address persistent state, executable rules, and low-latency interaction that purely video-based approaches struggle with.

### Ropedia W0 world model spans human and robot embodiments
`research` `robotics` (tagged by fallback) · 1 source

Researchers introduce Ropedia W0, said to be the first egocentric world model covering loco-manipulation across both humans and robots, trained on a new mixed human-robot dataset.

<details><summary>More</summary>

The model aims to jointly handle locomotion and manipulation across different robot embodiments, a problem the authors say is hard because of heterogeneous action spaces and limited multimodal supervision. To train it, the team curated Xp-Data, combining 10,000 hours of egocentric human video with 3,000 hours of robot data under unified multimodal annotations. The goal is a world model that lets embodied agents anticipate the consequences of their actions. The excerpt does not say how the model was evaluated or how it performs.

- [Hugging Face Daily Papers: Ropedia W0: Scaling Loco-Manipulation World Models across Embodiments with Human Experience](https://huggingface.co/papers/2610.26855)

</details>

## 🤖 Agents

### S-Agent 2.0 pairs a coding agent with 3D perception tools for spatial reasoning
`agents` `research` (tagged by fallback) · 1 source

S-Agent 2.0 is a general coding agent for spatial reasoning that actively gathers 3D evidence with perception tools rather than answering in one pass; the paper flags a persistent gap between correct tool readings and correct conclusions.

<details><summary>More</summary>

Spatial reasoning requires a model to work out where objects are in 3D space, how they relate to each other, and how they move. Earlier agentic vision-language models improved on these tasks by letting the model actively gather evidence with 3D perception tools instead of answering in a single pass. Even so, the authors find that on many questions the tools return correct evidence yet the model still reaches the wrong answer. They describe this as a gap between the model and its tools, where raw sensor readings fail to become usable conclusions.

- [Hugging Face Daily Papers: S-Agent 2.0: Spatial Reasoning with a General Coding Agent](https://huggingface.co/papers/2610.28354)

</details>
