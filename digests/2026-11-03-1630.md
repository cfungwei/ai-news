### Researchers introduce CoworkOS, a harness for scaling long-horizon agent coworkers
`agents` `research` (tagged by fallback) · 1 source

A new paper introduces CoworkOS, a harness for long-horizon 'cowork' agents that separates task strategy from execution management to handle complex, multi-step productivity work.

<details><summary>More</summary>

### CUA-Master framework scales computer-use agents via recursive self-improvement
`agents` `research` (tagged by fallback) · 1 source

A new paper presents CUA-Master, a nested double-loop framework for improving computer-use agents by generating more diverse and reliable interaction data instead of relying only on self-generated experience.

<details><summary>More</summary>

The researchers say progress on computer-use agents has been limited by a lack of diverse, controllable, and reliable interaction data, and that conventional training pipelines lack iterative feedback. Existing recursive improvement methods often rely solely on self-generated experience, which limits capability gains and produces diminishing returns. CUA-Master is designed as a nested double-loop recursive improvement framework operating at the system level to address these gaps.

- [Hugging Face Daily Papers: CUA-Master: Scaling Computer-use Agents through Open-World Recursive Improvements](https://huggingface.co/papers/2611.03126)

</details>

### NorthCUA harness turbocharges computer-use agents with large-scale experience data
`agents` `research` (tagged by fallback) · 1 source

A new technical report describes NorthCUA, a system that scales computer-use agents by generating and curating large volumes of task experience to connect agent decisions to full task outcomes.

<details><summary>More</summary>

The researchers argue that scaling computer-use agents from individual actions to complex software work requires experience linking decisions to complete outcomes. NorthCUA's 'Experience Flywheel' supplies diverse, executable tasks to the NorthCUA Harness, which sustains long interactions, records decisions, and checks task outcomes. The Flywheel then uses these records to curate verified trajectories for training.

- [Hugging Face Daily Papers: NorthCUA Technical Report: Turbocharging Computer-Use Agents through Experience at Scale](https://huggingface.co/papers/2611.02102)

</details>

### Study maps how computer-use agents recover, or fail to, from errors
`agents` `research` (tagged by fallback) · 1 source

A new paper examines why computer-use agents struggle to recover from mistakes in long-horizon tasks, where errors accumulate and leave unintended side effects.

<details><summary>More</summary>

Computer-use agents built on large vision-language models can automate digital workflows through fine-grained keyboard and mouse actions, but they remain fragile over long-horizon tasks. Errors accumulate and executed actions can leave unintended side effects, making recovery from failure critical. The researchers find existing remedies are inadequate: environment resets are not feasible in proprietary settings, and action replay is prohibitively expensive.

- [Hugging Face Daily Papers: Lost in Recovery: Demystifying Recovery Behavior of Computer-Use Agents via Goal-Oriented Action Replay](https://huggingface.co/papers/2610.27954)

</details>

### Open harness uni-robot-agent tops GPT-6's Astra-RoboProbe on RoboDojo benchmark
`robotics` `open-source` `research` (tagged by fallback) · 1 source

A new paper introduces uni-robot-agent, an open-weight harness for robot-use agents that lets researchers train models without relying on proprietary systems.

<details><summary>More</summary>

Robot-use agents have shown strong zero-shot manipulation abilities, but research has been constrained by dependence on frontier proprietary models that limit further training. Uni-robot-agent is a unified harness for competitive open-weight robot use that supports additional training. Without privileged inputs, an off-the-shelf Qwen3.8-Flash-Next model running on the harness scored 31.39 on the RoboDojo benchmark, surpassing the published GPT-6 Astra-RoboProbe score of 28.97 and other VLA/WAM baselines.

- [Hugging Face Daily Papers: Democratizing Robot-Use Agents: A Unified Harness with Open Models](https://huggingface.co/papers/2611.01560)

</details>
