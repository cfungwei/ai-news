### MemOnce proposes scalable memory architecture to cut LLM context costs

<details><summary>More</summary>

Deploying LLMs for long-horizon and continual interactions requires maintaining reusable memory states for future inference, which existing architectures struggle with. Standard Transformers accumulate layer-wise, token-level KV caches, causing linear GPU memory growth and quadratic computational complexity as context expands. Linear-time architectures instead compress history into fixed-size states, but struggle to retain fine-grained details. MemOnce is introduced to address this tradeoff, though the excerpt cuts off before explaining its specific mechanism.
