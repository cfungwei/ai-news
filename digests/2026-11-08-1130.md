### Datasette stops sending 'link: rel=next' prefetch headers to Firefox
`other` (tagged by fallback) · 1 source

Simon Willison describes a Datasette fix (issue #3046) that stops sending 'link: rel="next"' HTTP headers to Firefox, which had been triggering unwanted prefetches of table pages.

<details><summary>More</summary>

Willison writes that Firefox's network panel showed Datasette table pages triggering an HTTP prefetch of the next page of rows, caused by an HTTP 'link: rel="next"' header. He notes this is wasteful because only a small fraction of visitors to such pages click through to the next page, so prefetching wastes bandwidth. The fix, tracked as issue #3046, stops serving that header to Firefox for HTML pages.

- [Simon Willison: datasette #3046: Don't serve link: rel=next HTTP headers to Firefox for HTML pages](https://simonwillison.net/2026/Nov/7/link-rel-next/)

</details>
