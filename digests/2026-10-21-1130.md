### PAR method aims to fix length generalization in looped language models
`research` (tagged by fallback) · 1 source

A new technique called Progress-Aligned Recurrence trains looped language models to match their internal state after each reasoning step, aiming to fix poor length generalization in state tracking.

<details><summary>More</summary>

Looped language models can run extra iterations at test time, but the paper notes this doesn't reliably help them solve longer problems, since final-answer supervision doesn't specify how far each iteration should advance. PAR trains the prediction at each iteration to match the state after that many operations, and rescales the recurrent state relative to its first iteration. The excerpt does not include evaluation results.

- [Hugging Face Daily Papers: PAR: Progress-Aligned Recurrence for Length Generalization in State Tracking](https://huggingface.co/papers/2610.27628)

</details>

### SWIFT uses a frozen weak model to sharpen diffusion training for free
`research` `models` (tagged by fallback) · 1 source

SWIFT is a self-guided training method that uses a frozen weak denoiser to improve a stronger diffusion model's quality without adding cost at inference time.

<details><summary>More</summary>

Training high-quality diffusion models is expensive, and guiding them at inference time usually adds further sampling cost. SWIFT instead extrapolates the clean regression target away from a frozen weak denoiser's prediction for each noisy input, amplifying the components the stronger model still underfits. The weak guide can be an early checkpoint of the same model. The excerpt does not report specific quality gains or benchmark comparisons.

- [Hugging Face Daily Papers: SWIFT: Self-guided Weak-to-strong dIFfusion models via Target extrapolation](https://huggingface.co/papers/2610.25844)
