### Paper finds coding agents are better visual reasoners than video models
`research` `agents` (tagged by fallback) · 1 source

A new paper compares video generation models against coding agents that write and run code on the same visual reasoning tasks, finding the symbolic, code-based approach performs more reliably than native video-based reasoning.

<details><summary>More</summary>

The paper evaluates video generation models as visual reasoners, where a model is given a first frame and a prompt and must produce a video carrying out the specified task. That approach is seen as advantageous because reasoning happens directly in the visual medium rather than through language or code. The researchers test this native video-based reasoning against a symbolic alternative: coding agents that write and execute code to solve the same tasks. They find the code-based coding-agent approach is the stronger and more reliable visual reasoner of the two. The excerpt available does not specify which benchmarks or task categories were used for the comparison.

- [Hugging Face Daily Papers: Solve Vision with Code: Coding Agents Are Stronger Visual Reasoners Than Video Models](https://huggingface.co/papers/2611.34813)
