### WeChat releases WeVisOne-VL for unified visual perception
`research` `models` (tagged by fallback) · 1 source

Researchers present WeVisOne-VL (WeChat Vision All-in-One), a vision-language model that unifies object- and pixel-level visual perception through structured next-token prediction.

<details><summary>More</summary>

The paper argues that existing vision-language models remain unreliable for fine-grained visual perception, which WeVisOne-VL is built to address. It unifies object-level and pixel-level perception through structured next-token prediction, rather than handling each task with a separate head. The model supports object detection, referring localization, counting, OCR, segmentation, and matting within one system. It can localize at any granularity a user specifies, from points and boxes to masks and alpha mattes.

- [Hugging Face Daily Papers: WeVisOne-VL: Unified Visual Perception from Objects to Pixels](https://huggingface.co/papers/2610.31329)

</details>

### LayerEditor turns image edits into reusable RGBA layers
`research` `tools` (tagged by fallback) · 1 source

A new framework, LayerEditor, couples instruction-guided image editing with generation of reusable RGBA layers, aiming to make precise local edits without disturbing untouched regions.

<details><summary>More</summary>

High-quality image editing needs precise changes to target regions while leaving unrelated content untouched, something the paper says existing models struggle with. Current editing models produce flattened outputs that limit precise local manipulation and layer reuse. Separate decomposition methods, meanwhile, typically optimize layer recovery apart from instruction-driven editing. LayerEditor is presented as a unified framework that couples instruction-guided editing with controllable generation of reusable RGBA layers, aiming to close that gap.

- [Hugging Face Daily Papers: Editing Images into Reusable Layers via Compositional Edit-Prior Distillation](https://huggingface.co/papers/2610.24738)

</details>

### Paper charts a path to recursive self-improvement in physical AI
`research` `robotics` (tagged by fallback) · 1 source

A paper positions recursive self-improvement, systems that improve both their behavior and how they improve, within robot learning, where real-world trials are costly and risky.

<details><summary>More</summary>

Recursive self-improvement describes a system that improves not just its behavior but also the process by which it improves. Recent digital agents have tested the idea by rewriting their own code and checking each version with executable tests. Moving these mechanisms into the physical world is harder: it requires learning from partial observations through costly trials, while accounting for changing operating conditions and potentially irreversible consequences. The paper positions recursive self-improvement within robot learning in light of these constraints.

- [Hugging Face Daily Papers: Toward Recursive Self-Improvement in Physical AI](https://huggingface.co/papers/2610.29677)

</details>

## 🧠 Models

### IQuest-Q1 is a 320B MoE model built for agentic CLI systems
`models` `agents` `research` (tagged by fallback) · 1 source

Researchers present IQuest-Q1, a sparse Mixture-of-Experts foundation model with 320 billion total parameters (15 billion active), built for agentic command-line systems.

<details><summary>More</summary>

IQuest-Q1 is a sparse Mixture-of-Experts foundation model with 320 billion total parameters, of which 15 billion are active at a time, aimed at agentic command-line systems. It is built through a three-stage process, starting with stable and efficient pre-training that combines techniques the authors call Stable SplitNorm, Muon, and muP. That stage uses a two-stage curriculum whose second phase increases the share of coding data, while preserving a wide stability margin between safe and optimal learning rates. A second, fine-grained mid-training stage then expands the data mixture across further domains and formats.

- [Hugging Face Daily Papers: IQuest-Q1: Advancing Foundation Capabilities for Agentic CLI Systems](https://huggingface.co/papers/2610.30949)

</details>
