### New research links LLM agent memory failures to missing evidence
`research` `agents` (tagged by fallback) · 1 source

A new paper finds that external memory can degrade LLM agents' performance when they follow lessons distilled from past trajectories without the evidence behind them, causing agents to fail tasks they'd otherwise solve.

<details><summary>More</summary>

The paper, titled "Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents," describes how agents using external memory distill past task trajectories into concise lessons for future use. The problem arises because those lessons are inferred from trajectories labeled only by success or failure, with the underlying trajectory itself typically left out. An agent can then misapply or misread a lesson it has no way to verify, causing it to fail tasks it would otherwise have solved. The proposed fix, evidence-linked memory, ties each lesson back to the trajectory evidence it came from. The excerpt does not say how much the method improves task success or which agents or benchmarks were tested.

### Tree-Ising method repairs language models via bit-level weight edits
`research` `models` (tagged by fallback) · 1 source

A new technique called Tree-Ising repairs language model reasoning errors by directly editing the model's BF16 weights as a discrete optimization problem, avoiding the costlier agent-driven process used by a prior MIT approach.

<details><summary>More</summary>

The paper builds on recent MIT work by Takehi et al. on weight-space programming, where a frontier LLM agent reads a network's weights and writes a repair directly. In that prior approach, a "GPT-6 Astra" agent corrected reasoning loops in Qwen3.5-0.8B without gradients, but needed 158 agent turns, 89.7 million tokens, and 50 forward-pass requests. Tree-Ising instead casts the repair as a sparse discrete optimization problem over the model's own BF16 weights, using forward statistics to define an objective that weakens a problematic loop direction. The excerpt does not specify how the new method's cost or accuracy compares to the agent-driven baseline.

- [Hugging Face Daily Papers: Tree-Ising: Repairing Language Models with Bit-Level Ising Edits](https://huggingface.co/papers/2611.14210)

### Paper proposes world in-context learning for robot manipulation
`research` `robotics` (tagged by fallback) · 1 source

A new paper introduces "world in-context learning," letting robots use in-context demonstrations without being tied to the exact scene they were recorded in, aiming to match the performance of trained manipulation policies.

<details><summary>More</summary>

Trained action policies encode manipulation skills into network weights, tying what they learn to the distribution they were trained on. In-context learning (ICL) avoids that coupling but has lagged behind trained policies because a demonstration recorded in one scene offers no feedback from the world the robot currently faces. The authors observe that what an agent learns in context is largely semantic -- task steps and object roles -- rather than tied to visual appearance, meaning experience from one scene can transfer to another. The excerpt is cut off before describing the method's results or how it was evaluated.

### New method speeds up few-step streaming video generation
`research` `models` (tagged by fallback) · 1 source

A new paper extends the APEX technique to streaming video generation, using "condition shifting" to estimate the model's own velocity field instead of training a separate fake-score network.

<details><summary>More</summary>

Few-step sampling lowers the cost of streaming video generation, and Distribution Matching Distillation (DMD) is a common way to supervise few-step generators. DMD typically relies on a separate fake-score network, which adds training memory and computation and must be kept in sync with the evolving generator. The new method extends an existing technique called APEX to the streaming video setting by using condition shifting to estimate the velocity field of the generated distribution directly within the generator. It uses the original text condition to select generation and a shifted condition for fake-score estimation, avoiding the extra network. The excerpt cuts off before detailing results or benchmarks.

- [Hugging Face Daily Papers: Few-Step Streaming Video Generation via Condition Shifting](https://huggingface.co/papers/2611.14033)

</details>
